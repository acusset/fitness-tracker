# Fitness Tracker – Slides

Presentation deck for the Fitness Tracker project, built with [Slidev](https://sli.dev).

## Prerequisites

- Node.js ≥ 18

## Getting started

```bash
cd slides
npm install
npm run dev
```

Open <http://localhost:3030> in your browser to view and edit the slides live.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the development server with hot-reload |
| `npm run build` | Build the slides as a static site into `dist/` |
| `npm run export` | Export the slides to a PDF |

## Editing slides

All slide content lives in [`slides.md`](./slides.md).  
Slidev uses standard Markdown with a few extras – see the [Slidev docs](https://sli.dev/guide/) for the full syntax reference.
